Wi-Fi CSI Sensing Testbed
Device-free human pose estimation
Linux kernelIntel 5300 802.11 CSIPython

Brought up a legacy Linux Wi-Fi sensing rig by downgrading to kernel 3.14 and building the patched Intel 5300 CSI Tool driver from source, resolving kernel/driver compatibility along the way — enabling per-packet CSI capture over a 2-antenna NIC with a phone hotspot as transmitter.

Found that models trained on public 3-antenna CSI datasets do not transfer to 2-antenna captures, since antenna configuration changes the CSI matrix structure — then built a pipeline to synchronise CSI captures with pose labels for aligned training.
